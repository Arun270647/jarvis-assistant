Jarvis

A free, open-source voice assistant for Windows and Mac. It hears and speaks on your computer, and works with your own Claude account or another AI.

Download

Download for Windows

Windows 10 or 11, 64-bit. About 300 MB; the setup downloads the speech and voice models after that.

Download for Mac

Macs with Apple silicon (M1 or later), macOS 13 or later. Not for Intel Macs.

Install it on Windows in three steps

  1. Open your Downloads folder, right-click the zip file and choose Extract All, then Extract.
  2. Open the extracted Jarvis folder and double-click Jarvis.exe.
  3. The setup asks for a name, downloads the models and connects your AI. At the end, Install for me moves Jarvis out of Downloads and adds it to the Start Menu.

"Windows protected your PC"

Jarvis is free and has no budget for a code-signing certificate, so Windows SmartScreen warns the first time you open it. Click More info, then Run anyway. Windows only asks once.

To make sure the file is the one published here, open PowerShell in your Downloads folder and run:

Get-FileHash Jarvis-windows-x64.zip

Install it on a Mac in three steps

  1. Open the downloaded .dmg file and drag Jarvis onto the Applications folder next to it.
  2. Open Jarvis from Applications. The first time, follow "macOS can't check Jarvis" below.
  3. The setup asks for a name and for the microphone, downloads the models and connects your AI. Then you can eject the Jarvis disk image and delete the .dmg file.

"macOS can't check Jarvis"

Jarvis is free and isn't notarized by Apple (that needs a paid developer account), so macOS blocks it the first time. Click Done, open System Settings › Privacy & Security, scroll down to the message about Jarvis and click Open Anyway, then Open. macOS only asks once.

To make sure the file is the one published here, open Terminal in your Downloads folder and run:

shasum -a 256 Jarvis-macos-arm64.dmg
